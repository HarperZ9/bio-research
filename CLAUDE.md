# bio-research

Private research repo for the operator's primary focus: neurobiology (trauma,
amygdala-PFC, neuronal microtubules, optogenetics, activity-dependent grey
matter) and Pacific Northwest forest pathology and mycology.

## Projects
1. Amygdala-vmPFC connectivity in trauma: does it replicate on open data?
2. Stress and activity-dependent grey matter change (longitudinal MRI).
3. Optogenetics: opsin kinetic models in an amygdala-PFC circuit model.
4. Mycorrhizal network ("mother tree") claims: evidence audit.
5. Root disease (Armillaria, laminated root rot) from remote sensing.
6. Phytophthora ramorum spread forecasting, southwest Oregon.
7. Neuronal microtubules: stability, tau, and stress.

## Rules
- Every project names the decision it informs and a verifier the model did
  not see (held-out data, replication, field survey, cited primary source).
- Every citation carries a URL or DOI that was opened and checked. Unchecked
  citations are marked UNVERIFIED. No citation from memory alone.
- Separate observed, inferred, proposed and unknown. Every finding ships a
  "does not prove" line. Honest nulls stay.
- Pathogen work is detection, ecology and management only. Never anything
  that increases a pathogen's virulence, host range or spread.
- Human data: only data whose terms allow this use; no re-identification;
  credentials stay with the operator.
- Briefs live in project-docs/briefs/, findings in project-docs/FINDINGS.md.
